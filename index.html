Testagon - LLM Powered Unit Test Generation

Developed a tool that leverages LLMs to reason about logic invariants in your python programs and uses them to generate a suite of comprehensive unit tests. This was a group effort as part of the graduate Computer Security course at UCSB.

Follows the Actor-Critic method, creating a feedback loop that finds logic vulnerabilities in your source code. The “Actor” detects invariants and writes them into the docstring of your program files. It generates a test directory and writes unit tests for each one of your program files, allowing the invariants to guide the process. The “Critic" evaluates your program on the unit tests and records the response. It Sends the response back to the “Actor” to restart the process, aiming to refine the tests and invariants.

Built with Python and uses GPT-4o with structured JSON output support

ChatGPT as an Automatic Bug Fixer

In this project, we benchmark ChatGPT's performance on our self-curated, random dataset of “buggy” Leetcode problems to investigate the impact of three varying levels of context in the prompts we provide to ChatGPT.

Interestingly, we saw a marked decrease in GPT's program repair performance when the function and variable names were obfuscated.

This project was done as part of CS272, UCSB's graduate Software Engineering course.
