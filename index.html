Towards Efficient and Robust Vision-Language-Action Models

I built this project along with my groupmates for a Robot Learning course at UCSB. Below are the main features and contributions.

Replaced the LLaMA2-7B architecture in OpenVLA with TinyLlama-1B, then trained and finetuned on Llava-1.5 instruct, OpenX Embodiment, and LIBERO datasets

Conducted systematic adversarial noise evaluations on OpenVLA, identifying failure points and proposing improvements to increase resilience against real-world perturbations

Built with OpenVLA, PrismaticVLM, PyTorch, LoRA, and Python

Context-Aware Saliency for Rential Implant Users

I built this project along with my groupmates for a Bionic Vision course at UCSB. Below are the main features and contributions.

Developed a context-aware salient object detection pipeline that integrates YOLOv8 for segmentation and GPT-4o for object saliency ranking and classification, enhancing bionic vision for retinal implant users

Built with YOLOv8, OpenCV, GPT-4o and Python
